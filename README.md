# Learn-Sphere
A course and learning management system where students can browse courses, enroll, track their learning progress, complete quizzes, mark lessons as completed, and provide feedback. The project also includes an analytics dashboard for administrators to monitor student engagement and course performance...

**Problem Statement**

Many students use different platforms to find courses, track learning progress, complete assessments, and monitor their performance. Educational institutions also need meaningful information about student engagement, course popularity, completion rates, and academic performance.

Existing basic course-management systems often focus mainly on storing course information rather than analyzing learning behavior.

LearnSphere aims to provide a centralized platform where students can manage their learning activities while administrators can analyze learning data and generate meaningful insights using SQL, Python, and Power BI.

**Main Objective**
To develop a centralized student learning platform with an integrated analytics system that helps students manage their courses and helps administrators make data-driven decisions about learning performance and course effectiveness.


**Specific Objectives**

**Student Side**

Browse available courses,
Search and filter courses,
Add courses to favorites,
Enroll in courses,
Track course progress,
Complete lessons,
Attempt quizzes,
View quiz performance,
Submit feedback and ratings,
View personal learning statistics.

**Admin Side**

Manage students,
Manage courses,
Manage instructors,
Manage categories,
Manage lessons,
Monitor enrollments,
Monitor student progress,
Analyze quiz performance,
Analyze course ratings,
Generate reports.

**Analytics**

Identify popular courses,
Analyze student engagement,
Calculate course completion rates,
Analyze quiz performance,
Compare course categories,
Analyze instructor performance,
Identify courses with high enrollment but low completion,
Generate actionable insights.
