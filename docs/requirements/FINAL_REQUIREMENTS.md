# 1. Project Objective

LearnSphere is a student learning and course analytics platform that allows
students to explore courses, enroll, track learning progress, complete
quizzes, manage favorites, and view their learning performance.

The system also provides administrators with analytical insights into
student engagement, course performance, enrollment trends, completion rates,
and quiz performance using SQL, Python, and Power BI.

---

# 2. User Roles

## Student

- Browse courses
- Search courses
- Filter courses
- View course details
- Enroll in courses
- Add courses to favorites
- Track learning progress
- Complete lessons
- Take quizzes
- View quiz scores
- Submit reviews
- View learning statistics

## Instructor

- View assigned courses
- Manage course information
- Manage lessons
- View enrolled students
- View course performance

## Admin

- Manage students
- Manage instructors
- Manage courses
- Manage categories
- Monitor enrollments
- View analytics
- Generate reports
